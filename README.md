# Reading List Site

A brutalist black-and-white book list site. No backend, no database — just static files.

## Files

- `index.html` / `main.js` — home page, renders the ACTIVE/ARCHIVE grids from `books.js`
- `book.html` / `book.js` — detail page for a single book
- `books.js` — the data: title, author, year, cover, status, blurb
- `style.css` — all styling
- `covers/` — cover images
